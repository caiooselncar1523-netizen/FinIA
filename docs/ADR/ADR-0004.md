# ADR-0004: Limites de atuação do assistente de IA

**Status:** Aceito
**Data:** 2026-09-17

## Contexto

Um assistente de IA com acesso aos dados financeiros do usuário pode, tecnicamente, ser usado para recomendar compra/venda de ativos específicos. No Brasil, esse tipo de recomendação personalizada se enquadra como consultoria de investimentos, atividade regulada pela CVM. O produto precisa decidir, desde o design, até onde a IA pode "opinar".

## Decisão

O assistente de IA do FinIA:

- **Pode**: analisar padrões de gastos, explicar dados da carteira, sugerir ajustes de orçamento/hábitos financeiros, responder perguntas educativas genéricas sobre finanças.
- **Não pode**: recomendar compra/venda de ativos específicos, fazer projeções de rentabilidade futura como garantia, ou qualquer output que se caracterize como consultoria de investimento personalizada.

Essa fronteira é aplicada via prompt de sistema do assistente e reforçada com aviso visível na interface do chat.

## Alternativas consideradas

- **IA sem nenhuma restrição, deixando o usuário responsável pelo uso** — descartado por expor o produto a risco regulatório desnecessário logo num projeto de portfólio.
- **IA totalmente passiva (só mostra dados, zero interpretação)** — descartado por tornar o diferencial de "IA" do produto fraco demais; não usa o potencial real de um LLM.

## Consequências

- O prompt de sistema do assistente precisa ser versionado e revisado como parte do código (não é só um detalhe de produto — é uma decisão técnica com impacto direto em compliance).
- Testes automatizados devem incluir casos que verificam se o assistente recusa corretamente pedidos de recomendação de ativos (ex: "devo comprar PETR4?").
- Referência cruzada: essa decisão também está documentada na seção 5.1 do PRD (`docs/PRD.md`).
