# ADR-0003: Brapi.dev como fonte de dados de mercado

**Status:** Aceito
**Data:** 2026-09-17

## Contexto

O módulo de investimentos precisa de cotações de ativos (ações, FIIs, cripto, câmbio) e indicadores macroeconômicos (SELIC, CDI, IPCA) do mercado brasileiro, de forma confiável e sem custo na fase de MVP.

## Decisão

Usar a **Brapi.dev** como fonte primária de dados de mercado.

## Alternativas consideradas

- **Alpha Vantage** — boa para mercado global, mas cobertura de ativos brasileiros (FIIs, BDRs) é limitada e o limite de chamadas gratuito é mais restritivo.
- **Yahoo Finance (bibliotecas não oficiais)** — gratuito, mas sem SLA, sujeito a quebrar sem aviso por não ser uma API oficialmente suportada.
- **Dados abertos da B3/CVM diretamente** — oficiais e confiáveis, mas em formato bruto, exigindo bem mais trabalho de parsing e normalização do que o MVP justifica.

Brapi.dev venceu por unificar ações, FIIs, cripto, câmbio e macro brasileiro em uma única API com SDK pronto, o que reduz tempo de integração no MVP.

## Consequências

- Dependência de um único provedor externo — se a Brapi.dev mudar termos ou sair do ar, o módulo de investimentos é impactado. Mitigado por manter a camada de acesso a dados de mercado isolada (padrão adapter/repository), facilitando trocar de provedor no futuro sem reescrever regras de negócio.
- Necessário monitorar o limite de requisições do plano gratuito e usar o cache Redis (ver ADR-0002) para não estourá-lo.
